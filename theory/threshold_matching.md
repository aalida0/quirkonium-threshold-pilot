# Threshold matching — STOP/UNKNOWN
A physical exclusive muon final state requires a correctly renormalized/matched vector-current correlator Pi_V(q²), coincident Green function G(0,0;E), hard current coefficients, matched pole residues, and a defensible treatment of hidden colored pair confinement. Do not add separate Breit–Wigner poles to G, which already contains them. A positive smoothing regulator is not the physical Γ_total. A linear static potential has discrete IC-singlet levels; do not simply import the free t tbar continuum from top-threshold production. Bai–Chen–Yang arXiv:2506.14552 Eqs.2.19–2.23 supply useful Coulomb methods, but NOT a validated quirk matching formula. None of these steps was implemented.
